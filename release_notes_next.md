# Следующий релиз

- Исправлена загрузка геофайлов подписок размером больше 64 МБ. Базы до 256 МБ скачиваются во временный файл и проверяются перед заменой кеша. При ошибке обновления рабочая копия сохраняется. Конвертер маршрутизации загружает в память только выбранную категорию.
- HTTPS-прокси отображаются как HTTPS, если используется TLS. Импорт, сохранение и экспорт сохраняют TLS и настройки проверки сертификата.
- В настройках VK под статусом привязки показан только ID аккаунта приглушённым цветом, без имени и префикса.
- Убрано повторное модальное предупреждение после сохранения настроек TUN. Уведомление о необходимости перезапуска в главном окне сохранено.
